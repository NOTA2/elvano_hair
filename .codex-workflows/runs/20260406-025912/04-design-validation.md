# 디자인 검증

- 도구: Playwright
- 확인 URL: `http://localhost:3000/admin`

# 확인 결과

- 393px 폭에서 상단 GNB가 전체 폭으로 고정되고, 우측 햄버거 버튼이 명확하게 분리되어 보였다.
- 모바일 메뉴를 열면 드로어가 GNB 아래에서 자연스럽게 열리고, 배경 딤과 스크롤 잠금이 정상 동작했다.
- 1024px 폭에서도 상단 GNB 잘림 현상이 사라졌고, 이전처럼 40px 폭 버튼만 남는 문제를 재현하지 못했다.
- 1440px 폭에서는 기존 좌측 사이드바가 유지되고 모바일 GNB는 숨겨져 PC 레이아웃 회귀가 없었다.

# 잔여 관찰

- 관리자 대시보드 차트 영역은 모바일에서 내부 가로 스크롤이 남아 있다.
- 이번 요청의 핵심 이슈는 네비게이션이었고, 차트의 모바일 정보 밀도는 별도 개선 과제로 분리하는 편이 안전하다.
