# 실행 계획

1. 로그인된 관리자 화면을 Playwright로 열고, 모바일 메뉴 열기 동작과 1024px 전후 레이아웃을 재현한다.
2. 모바일 상단 UI를 "고정 GNB + 우측 햄버거 버튼" 구조로 분리한다.
3. 모바일 드로어는 기존 관리자 사이드바 내용을 재사용하되, 오픈 시 바디 스크롤 잠금과 닫기 동작을 유지한다.
4. 데스크톱에서는 기존 좌측 사이드바를 유지하고 모바일 GNB는 숨긴다.
5. `npm run build`, `npm run validate:performance`, Playwright 재검증 결과를 기록한다.

# 주요 리스크

- 모바일 GNB가 폭 0인 사이드바 컨테이너 영향을 받아 잘릴 수 있다.
- 1024px 근처에서 데스크톱과 모바일 규칙이 겹치며 레이아웃이 깨질 수 있다.
- 드로어 오픈 상태가 라우트 전환이나 리사이즈 이후에 남아 UX를 망칠 수 있다.

# 검증 기준

- 393px 폭에서 상단 GNB가 전체 폭으로 보이고 햄버거 버튼이 오른쪽에 고정된다.
- 햄버거 버튼 클릭 시 드로어가 열리고, 배경 딤 처리와 바디 스크롤 잠금이 동작한다.
- 1024px 폭에서도 상단 GNB가 잘리지 않는다.
- 1440px 폭에서는 기존 좌측 사이드바가 유지되고 모바일 GNB가 노출되지 않는다.
